💡 Mẹo Ôn Thi NWC204

  • TCP vs UDP: TCP tin cậy (3-way handshake, window, sequencing); UDP phi kết nối, overhead thấp (8 bytes).
  • IPv6 Rules: 128-bit hex; dấu :: chỉ được dùng 1 lần duy nhất để nén chuỗi số 0 liên tiếp.
  • Subnetting: /24=254 hosts, /26=62 hosts, /27=30 hosts, /30=2 hosts (point-to-point link).
  • Cisco Modes: > (User EXEC) → # (Privileged EXEC) → (config)# (Global config).
